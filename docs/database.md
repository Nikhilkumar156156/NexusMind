# Database Architecture & Schema: Smart Care Navigator

**Database Engine:** PostgreSQL 16+  
**ORM / Schema Layer:** Drizzle ORM  
**Migration Strategy:** Declarative Drizzle Kit Migrations  

---

## 1. Schema Design Principles

The database schema is intentionally streamlined for the 36-hour MVP:
1. **Lightweight & High-Performance**: Optimized for rapid reads and writes during urgent triage evaluations.
2. **Strict Privacy**: No unnecessary patient PII is stored. Triage sessions can run anonymously or with a temporary session token.
3. **Resilient Facility Caching**: Hospital research outcomes from Agent 2 (Google Search MCP) are cached with source citations, reducing latency and redundant search calls.

---

## 2. Table Definitions (DDL)

### 2.1 Triage Sessions & Clinical Assessments
Stores the symptom inputs and clinical triage classifications generated by Agent 1.

```sql
CREATE TYPE urgency_level AS ENUM ('CRITICAL', 'URGENT', 'NON_URGENT');

CREATE TABLE triage_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_token VARCHAR(64) NOT NULL,
    age INTEGER NOT NULL,
    sex VARCHAR(16) NOT NULL,
    location_name VARCHAR(128) NOT NULL,
    latitude REAL,
    longitude REAL,
    primary_symptoms TEXT NOT NULL,
    additional_symptoms TEXT,
    severity VARCHAR(32) NOT NULL,
    duration VARCHAR(64) NOT NULL,
    vitals JSONB DEFAULT '{}'::jsonb NOT NULL,
    medical_history JSONB DEFAULT '[]'::jsonb NOT NULL,
    
    -- Agent 1 Triage Outputs
    urgency urgency_level NOT NULL,
    emergency_required BOOLEAN NOT NULL,
    required_specialty VARCHAR(64) NOT NULL,
    condition_category VARCHAR(128) NOT NULL,
    clinical_routing_advice TEXT NOT NULL,
    
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

CREATE INDEX idx_triage_sessions_token ON triage_sessions(session_token);
CREATE INDEX idx_triage_sessions_urgency ON triage_sessions(urgency);
```

### 2.2 Hospital Research & Verification Cache
Stores facility records discovered dynamically by Agent 2 (via Google Search MCP) or pre-seeded from regional health registries.

```sql
CREATE TYPE specialty_mode AS ENUM ('EMERGENCY_AND_OPD', 'OPD_ONLY', 'EMERGENCY_ONLY', 'UNKNOWN');
CREATE TYPE verification_status AS ENUM ('verified', 'partially_verified', 'unverified');

CREATE TABLE hospital_research_cache (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    facility_name VARCHAR(255) NOT NULL,
    normalized_name VARCHAR(255) NOT NULL,
    address TEXT NOT NULL,
    city_district VARCHAR(128) NOT NULL,
    latitude REAL,
    longitude REAL,
    contact_number VARCHAR(32),
    
    has_emergency_department BOOLEAN DEFAULT false NOT NULL,
    verified_specialties JSONB DEFAULT '[]'::jsonb NOT NULL,
    
    -- Dynamic OPD vs Emergency mapping per specialty
    -- Example: { "Neurology": "OPD_ONLY", "Cardiology": "EMERGENCY_AND_OPD" }
    specialty_availability JSONB DEFAULT '{}'::jsonb NOT NULL,
    
    verification_status verification_status DEFAULT 'unverified' NOT NULL,
    sources JSONB DEFAULT '[]'::jsonb NOT NULL,
    
    last_researched_at TIMESTAMPTZ DEFAULT NOW() NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

CREATE INDEX idx_hospitals_district ON hospital_research_cache(city_district);
CREATE INDEX idx_hospitals_normalized ON hospital_research_cache(normalized_name);
```

### 2.3 Facility Recommendations
Stores the ranked Top-5 output and explainable rationales generated by Agent 3 for a given triage session.

```sql
CREATE TABLE triage_recommendations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    triage_session_id UUID NOT NULL REFERENCES triage_sessions(id) ON DELETE CASCADE,
    rank INTEGER NOT NULL,
    facility_id UUID REFERENCES hospital_research_cache(id),
    facility_name VARCHAR(255) NOT NULL,
    distance_display VARCHAR(64) NOT NULL,
    emergency_dept_verified BOOLEAN NOT NULL,
    specialty_emergency_verified BOOLEAN NOT NULL,
    verification_status verification_status NOT NULL,
    
    -- Plain-language clinical explanation
    explanation TEXT NOT NULL,
    contact_number VARCHAR(32),
    navigation_uri TEXT,
    
    created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

CREATE INDEX idx_recommendations_session ON triage_recommendations(triage_session_id);
```

## 3. Query Optimization & Maintenance

1. **Cache TTL & Expiry**:
   - Hospital research records are valid for 7 days. If a triage request queries a facility older than 7 days, Agent 2 will trigger a background re-verification via Google Search MCP.
2. **Audit & Anonymity**:
   - Triage sessions are detached from direct personal identifiers (no patient names or contact numbers in `triage_sessions`).
